  • Open access

    Anyone on campus can book a venue, whether it's a student running a club or a department planning an event. Every space available is in one place, so there's no need to follow up with a different person for each venue.

  • Configurable requirements

    For a reserved space, you can request what the event needs: lighting, extended hours, catering or a seating setup. The request reaches the venue team along with the booking, so everything is arranged together instead of separate follow-ups.

  • Instant confirmation

    You pick an available slot, say what the event is for, and the booking is confirmed. If a student needs a free room for an hour, there's no request form sitting in someone's inbox.

  • Transparent pricing

    Some venues are free and some are paid, and you can see the distinction before committing. If a space isn't free, that cost is reflected, so the decision is made with complete information.
